# 🚀 Landing Page Responsive

Landing page de una sola página que se adapta a celular, tablet y computador. Es mi primer proyecto de portafolio como desarrollador Frontend.

**Demo en vivo:** [https://courageous-cassata-22f943.netlify.app/]

##Características

- Diseño **responsive**: se adapta a cualquier tamaño de pantalla
- Barra de navegación con **Flexbox**
- Sección hero con título, subtítulo y botón de acción
- Sección de beneficios con **CSS Grid** (`auto-fit` + `minmax`)
- Formulario de contacto con validación nativa del navegador
- Efectos `hover` y transiciones suaves

##Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, media queries, `clamp()`)
- JavaScript (manejo de eventos del formulario)

##Lo que aprendí

- Maquetar páginas con Flexbox y Grid
- Crear diseños responsive sin depender de muchas media queries
- Validar formularios y manejar eventos con JavaScript
- Usar Git y GitHub, y desplegar un sitio en Netlify

##Cómo ejecutarlo en local

1. Clona el repositorio:
   `git clone https://github.com/DamianVictoria/landing-page.git`
2. Abre la carpeta y haz doble clic en `index.html`
